# Neonize bridge: route coverage

Compared with the routes WPPConnect Server defines for WinZapp (`client/api/dist/routes/index.js`). The bridge implements **66 of 220**; **150** are not implemented. A missing route makes the feature that needs it unavailable (or a harmless 404 in the log) when the Neonize engine is selected.

This list is generated by comparing route names, so a feature may be reachable by another route than the one named here (for example, the client sends voice notes with `send-voice-base64` and files and photos with `send-file`, which are implemented).
